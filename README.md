# 📱 Almotasuq: Systems Analysis & Design Project

## 📌 Project Overview
**Almotasuq** is a comprehensive systems analysis and design project for a mobile application aimed at enhancing customers' daily lives. The platform serves as a centralized digital hub for exclusive discounts and offers across various sectors, including food, fitness centers, electronics, and online courses. Functioning as a digital Customer ID with an interactive map, the app is designed to reduce financial pressure, promote smarter spending habits, and eliminate the need for physical discount cards.

## ⚙️ Methodology & Architecture
The system was designed utilizing the **Agile Development Methodology** to ensure rapid adaptation, iterative updates, and a continuous focus on user feedback. The project encompasses a full system lifecycle modeling, documenting both functional and non-functional requirements to support a scalable architecture capable of handling 10,000+ concurrent users securely.

## 🚀 Key Deliverables & Achievements
* **Requirements Engineering:** Defined comprehensive functional workflows for Customers, Service Providers, and Administrators, alongside strict non-functional constraints (availability, data integrity, bilingual support).
* **Business Process Modeling:** Mapped complex business rules using **BPMN**, detailing the end-to-end flows for user registration, offer management, and coupon redemption.
* **Structural & Behavioral Modeling:** Developed complete UML documentation including Use Case Diagrams, Class Diagrams, Object Diagrams, and Sequence Diagrams to visualize system interactions and database relationships.
* **User Interface (UI) Prototyping:** Designed intuitive user interfaces demonstrating the user journey from browsing categorized deals to securing time-limited discount codes.

## 👨‍💻 My Contributions
As a core member of the system analysis team, I took full ownership of designing the data flow and physical system architecture. My specific technical contributions to this project included:
* **Data Flow Diagrams (DFD):** Mapped the precise movement of data between users, admins, and the underlying databases (Coupon DB, User DB, Store DB).
* **State Machine Diagrams:** Modeled the complex behavioral lifecycle and validation processes of the discount coupons and system objects.
* **Deployment Diagrams:** Architected the physical network topology, illustrating the secure connections and firewall placements between the user's smartphone, the main server, administrative nodes, and the database.
